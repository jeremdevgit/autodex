# Third-party components / Composants tiers

## Recognition model / Modèle de reconnaissance

- **ZEDEDA ResNet-50 Stanford Cars** — https://huggingface.co/zededa/resnet50-cars — Apache License 2.0.
- File `public/models/cars-int8.onnx` is an int8 dynamic quantisation of `resnet50_cars_enhanced.onnx`; `labels.json` lists the 196 classes in the order expected by the model. Accuracy is equivalent to the original on our test images.
- The model was trained on the **Stanford Cars** dataset (Krause, Stark, Deng, Fei-Fei, *3D Object Representations for Fine-Grained Categorization*, 2013). No image from the dataset is distributed with AutoDex.

## Data / Données

The catalogue (models, years, body types, representative power, indicative values, paint names) was compiled for AutoDex from public manufacturer information. Values are rounded estimates, not quotes. Brand and model names are trademarks of their owners; AutoDex is not affiliated with or endorsed by any manufacturer. 3D models and silhouettes are generic shapes generated by code, not manufacturer designs.
